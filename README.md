# FRAC-PPO
FRAC-PPO: Fixed-Resource Adaptive Coordination Proximal Policy Optimization for Spatial Public Goods Games

## Requirements
It is worth mentioning that because python runs slowly, we use cuda library to improve the speed of code running.

```
* Python Version 3.12.2
* CUDA Version: 12.8
* torch Version: 2.2.1
* numpy Version: 1.26.4
* pandas Version: 2.2.3
```

## Installation
```bash
conda env create -f environment.yaml
```

## Usage
run scripts of run_FRAC_PPO.sh:
```bash
sh scripts/run_FRAC_PPO.sh
```
